# Vórtex Calc

Vórtex Calc, de Vortex Company: calculadora científica con grados/radianes, memoria e historial guardado en tu equipo, más conversor de unidades offline (longitud, masa, temperatura, datos y más). Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
